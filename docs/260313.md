# 训练仓库最小闭环模块契约表（按当前代码实现）

> 状态更新（260317+）：本文中涉及 `training_repo` 线性 OpenPI 后端的内容已历史化，
> 当前仓库真实 PI 训练入口为 `scripts/train_pi.py` + `third_party/openpi`。

| 模块 | 输入 | 输出 | 不变量 | 失败时应做什么 |
| --- | --- | --- | --- | --- |
| ingest | `raw_data_root` 下原始 episode json | 标准化 episode 列表（`episode_id/task_id/source_path/num_steps/success/steps`） | step 按 `t` 升序；episode 和 step 必要字段齐全；`steps` 非空 | 立即失败并抛出明确异常：路径不存在（`FileNotFoundError`）、无 json/字段缺失/结构非法（`ValueError`，带文件路径与缺失键） |
| relabel | 标准化 episode + `pre_intervention_k` | 带标签 step（含 `sample_id/sample_type/label_source`） | `sample_id = {episode_id}:{t}`；`sample_type ∈ {correct, interaction, incorrect}`；每次 `intervention_flag` 从 `False->True` 的切换点都会触发 pre-intervention 回溯 K 步（不是仅第一次）并改成 `incorrect` | 对非法参数直接失败：`pre_intervention_k < 0` 抛 `ValueError`；其余逻辑异常应保留原始报错用于定位 |
| dataset_build | episodes + 构建配置（`val_ratio/split_mode/shard_size/...`） | OpenPI 可读数据包（`steps/`、`manifests/`、`labels/`、`meta/`） | 仅 `episode` 级 split；split 以 episode 为单位且同一 episode 的 step 不得跨 split；`sample_id` 全局唯一且格式固定；`bucket` 合法；`obs_state/action` 维度全局一致；统计只用 train split | 配置不合法或数据不一致时立刻中止：`val_ratio`/`split_mode`/`shard_size` 异常、重复 `sample_id`、维度不一致、train 为空均抛 `ValueError` |
| adapter | 数据包根目录（manifest/labels/steps/stats） | 按 split 的训练样本列表（含 step 字段 + 标签字段） | 以 `sample_id` 做跨文件对齐；`build_manifest.bucket` 与 label 的 `sample_type` 语义一致；样本字段最小集完整 | 文件缺失或 key 缺失时快速失败（`FileNotFoundError`/`KeyError`）；`sample_id` 跨文件对不齐时必须失败，不允许静默跳过或自动补齐 |
| train | OpenPI 配置名 + 训练超参（通过 `scripts/train_pi.py` 转发） | OpenPI checkpoint 目录（由 `third_party/openpi` 生成） | 训练仅走 `third_party/openpi` 官方入口；不再存在仓内线性 smoke 训练后端 | 若 `third_party/openpi` 不存在或参数非法，启动阶段直接失败并输出原生报错 |
| export | 导出配置（`artifact_dir/artifact_weights_file/tos_weights_path`） | `inference_bundle`（`inference_runner.py/model_spec.yaml/weights_locator.yaml/...`） | bundle 文件集固定；`model_spec` 维度由权重推导；`load_policy()` 返回含 `weight/bias/obs_mean/obs_std/action_mean/action_std` 的 policy 字典；`predict_action()` 最小输入是 1D `obs_state` 向量；输出 `action` shape 为 `[action_dim]`，由 `model_spec` 与权重形状共同定义 | 权重文件缺失时报 `FileNotFoundError`；权重数组缺 key/shape 不匹配时报 `ValueError`；输入 `obs_state` 维度不符时报 `ValueError` |

## 系统级不变量（横跨模块）

- `sample_id` 在整个 dataset package 内全局唯一。
- dataset build 产物一旦生成，训练与导出流程都不得回写修改该数据包。
- batch ratio 只存在于训练侧 sampler，不存在于 dataset build 产物定义中。
- inference bundle 运行时不依赖 training repo 内部复杂路径，仅依赖 bundle 内文件与 `weights_locator.yaml` 的权重定位约定。
