# 260317 训练入口统一结论（增量更新）

## 当前状态

仓库现在同时支持两条路径：

1. **真实 PI 官方训练路径（保持不变）**
   - 入口：`scripts/train_pi.py`
   - 转发到：
     - `third_party/openpi/scripts/train.py`（JAX）
     - `third_party/openpi/scripts/train_pytorch.py`（Torch）

2. **training_repo 多策略工厂路径（新增）**
   - 入口：`scripts/train_policy.py`
   - 分发规则：
     - `backend=openpi` 或 `backend=openpi_torch/openpi_jax` -> OpenPI backend
     - `backend=lerobot` 或 `policy.type in {act,diffusion,pi0,pi05}` -> LeRobot backend

## 新增文件

- `src/training_repo/train/backend_factory.py`
- `src/training_repo/backends/openpi_backend.py`
- `src/training_repo/backends/lerobot_backend.py`
- `scripts/train_policy.py`
- `configs/train_policy_openpi.yaml`
- `configs/train_policy_act.yaml`
- `configs/train_policy_diffusion.yaml`

## 使用示例

```bash
# OpenPI（真实 PI 训练）
python scripts/train_policy.py --config configs/train_policy_openpi.yaml

# ACT（LeRobot）
python scripts/train_policy.py --config configs/train_policy_act.yaml

# Diffusion（LeRobot）
python scripts/train_policy.py --config configs/train_policy_diffusion.yaml
```

## 260317 增量：策略 YAML 分层

为对齐 Kuavo 风格的「策略参数独立配置」，`scripts/train_policy.py` 这条链路现在支持分段 YAML 合并：

- 可选字段：
  - `policy_config`
  - `dataset_config`
  - `train_config`
  - `lerobot_config`
  - `openpi_config`
- 合并规则：
  - 先读取 `*_config` 指向的 YAML
  - 再用主配置里的同名 section（如 `policy`）做覆盖
  - 即“外部文件给默认值，主配置做实验级 override”

示例（ACT）：

```yaml
backend: lerobot
policy_config: policy/act.yaml
policy:
  device: cuda
dataset:
  repo_id: pipeline_ab/A
```

默认示例文件：

- `configs/policy/act.yaml`
- `configs/policy/diffusion.yaml`

## 260317 增量：pi05 LoRA（WBCD）严格对齐 OpenPI

`OpenPI` 侧已补充一个等价训练配置（配置名不是重点，字段与超参对齐才是重点）：

- `model`:
  - `Pi0Config(pi05=True, paligemma_variant="gemma_2b_lora", action_expert_variant="gemma_300m_lora")`
- `data`:
  - `repo_id=pipeline_ab/A`
  - 本地数据目录：`tmp/pipeline_ab/lerobot_v21_split/A`（由 `scripts/split_lerobot_v21_by_labels.py` 生成，需映射到 `HF_LEROBOT_HOME/pipeline_ab/A`）
  - 数据格式：LeRobot `v2.1`（OpenPI 当前运行时依赖 `lerobot.common` v2.1）
  - `adapt_to_pi=False`
  - `repack_transforms` 对齐三路图像键 + `state/action/prompt`
  - `base_config.prompt_from_task=True`
- `weight_loader`:
  - `gs://openpi-assets/checkpoints/pi05_base/params`
- `freeze_filter`:
  - 同构 LoRA `Pi0Config(...).get_freeze_filter()`
- 训练超参：
  - `num_train_steps=20000`
  - `batch_size=16`
  - `fsdp_devices=2`
  - `ema_decay=None`

对应 launcher 配置：`configs/train_pi05_openpi.yaml`

- backend: `openpi_jax`
- config_name: `pi05_aloha_wbcd_lora`
- extra_args:
  - `--project-name=EvoRL-Piper`
  - `--exp-name=evorl_pi05_lora_fullA_260317`
  - `--wandb-enabled`
  - `--overwrite`

启动命令：

```bash
CUDA_VISIBLE_DEVICES=5,7 python scripts/train_pi.py --config configs/train_pi05_openpi.yaml
```
