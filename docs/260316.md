# 260316：多类别人工标注、性能优化与数据集拆分流水线

## 本次新增

### 1) Headless 标注 GUI

- 脚本：`scripts/review_episode_tasks_gui.py`
- 主要能力：
  - SSH 隧道可用的 Web 标注界面
  - 同时展示三路视频（head/left_wrist/right_wrist）
  - 仅 `left_wrist_cam` 自动播放，其他视频手动检查
  - 标注类别后立即写入 CSV（避免断连丢标注）
  - 支持动态新增/删除类别，不再限制为固定 `A/B/uncertain`
  - 支持删除当前 episode 的标注记录（从 CSV 删除该行）
  - 支持视频播放倍速（含 2.0x）
  - 显示 `agent_pos` 关节角折线图（14 维）
  - 视频质量检查（分辨率、FPS、帧数、可打开、首帧解码）

### 2) GUI 速度优化

- 切换 episode 时不再同步执行质量检查（改为手动触发按钮）。
- 非左腕视频默认 `preload=none`，减少带宽占用。
- 关节曲线读取做前端缓存，重复访问同一 episode 不重复拉取。
- 保存标注后不再全量刷新左侧列表，降低保存延迟。

### 3) 一键流水线：CSV -> 回写 task_id -> 构建 A/B 数据集

- 脚本：`scripts/apply_labels_and_build.py`
- 输入：
  - `--raw-data-root`：原始 episode json 根目录
  - `--label-csv`：GUI 输出的 `task_labels.csv`
- 处理：
  - 按 `episode_id` 匹配标签并回写 `task_id`
  - 生成中间目录：`all_labeled`、`only_A`、`only_B`
  - 自动触发 `build_dataset` 两次
- 输出：
  - `A` 数据集目录：`<output-root>/A`
  - `B` 数据集目录：`<output-root>/B`

### 启动标注 GUI

```bash
PYTHONPATH=src python scripts/review_episode_tasks_gui.py \
  --video-root "<dataset>/videos" \
  --label-csv "<dataset>/task_labels.csv" \
  --host 127.0.0.1 \
  --port 18080
```

### GUI 操作补充（260316）

- 类别管理：
  - 支持新增类别（`新增类别` 按钮）
  - 支持删除类别（可选是否同时删除该类别已有标注行）
- 标注记录管理：
  - 支持删除当前 episode 标注记录（从 CSV 删除该行）
- 播放效率：
  - 支持倍速切换（`1.0x / 1.5x / 2.0x`）
  - 默认 `2.0x`
  - 快捷键 `X` 可在 `1.0x` 与 `2.0x` 之间切换

### 执行回写并构建 A/B

```bash
PYTHONPATH=src python scripts/apply_labels_and_build.py \
  --raw-data-root "<raw_episode_json_root>" \
  --label-csv "<dataset>/task_labels.csv" \
  --rewritten-raw-root "<rewritten_root>" \
  --output-root "<ab_dataset_root>" \
  --task-a-name shirt_open_middle \
  --task-b-name shirt_flatten \
  --drop-non-ab
```

- 若已出现嵌套目录，先确认目标数据已在正确位置，再删除冗余副本，避免误删。
